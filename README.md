# Open Coral Network / Plural Commons Japan 公式組織ハンドブック

特定非営利活動法人 Open Coral Network および Plural Commons Japan の公式組織ハンドブック（Mintlify ドキュメント）のリポジトリです。

## 📖 ハンドブックの内容

- **理念・組織憲章 (`foundation/`)**: 「組織のための個人」という基本哲学、日本の5大構造危機、Civic AI、Do-ocracyガバナンス
- **参画・拠点 (`participation/`)**: メンバー参加ステップ、ロール定義、連絡ツール運用、空き家サードプレイス拠点
- **エコシステム・仕事 (`ecosystem-jobs/`)**: 4大資金循環モデル、現場仕事創出、フェア・バウンティ、独自ポイント制度
- **実務・各種申請 (`operations/`)**: タスク推進ルール、経費精算・備品利用、コンプライアンス・セキュリティ規程
- **主要プロジェクト連携 (`projects/`)**: Plural Commons Japan 仕様書連携、Nexloom 統合ワークスペース仕様書連携

## 🚀 ローカル開発

```bash
npm install
npm run dev
```

ブラウザで `http://localhost:3333` を開いてプレビューできます。
