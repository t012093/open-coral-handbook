## 1. 3分でわかる JAPAN RWA VAULT

JAPAN RWA VAULTは、世界中のコレクターと日本のクリエイターを直結する**「自社スタジオ ＆ 現物裏付け型Web3コレクション金庫」**です。

新進気鋭の日本人アーティストを発掘・直契約し、自社スタジオで企画・製造された**「世界限定のアートトイ・フィギュア」や「大型現物絵画」**を中心に展開しています。

すべての作品は東京の自社セキュリティ金庫（Vault）で安全に保管され、ブロックチェーン上のNFTとして**国際送料・関税・破損リスクゼロで即座にP2P売買**が可能です。

## 3. システムアーキテクチャ

フロントエンド、スマートコントラクト、物理金庫、物流APIが疎結合に連携するハイブリッドWeb3構成です。

```mermaid
flowchart TB
    subgraph Client ["クライアント層 (Web3 Frontend)"]
        UI["Next.js / Tailwind CSS / Three.js 3Dビューア"]
        Wallet["Wagmi / viem / AppKit (MetaMask, Phantom, メールログイン)"]
    end

    subgraph Blockchain ["ブロックチェーン層 (Polygon & Arbitrum)"]
        NFT["VaultCardNFT.sol (ERC-721 + ERC-2981永続ロイヤリティ)"]
        Market["AtomicMarketplace.sol (ノンカストディアルP2P売買)"]
        VRF["MysteryBoxVault.sol (Chainlink VRF v2.5公正抽選)"]
    end

    subgraph Backend ["オフチェーン・バックエンド層"]
        API["Node.js / Fastify / TypeScript"]
        DB[(PostgreSQL / Prisma)]
        Oracle["Price Oracle Worker (グローバル相場クローリング)"]
    end

    subgraph Physical ["物理金庫 ＆ 物流 (Tokyo Vault)"]
        Warehouse["東京セキュリティ金庫 (24h恒温恒湿空調・動産総合保険)"]
        DHL["DHL Express API (輸出申告・自動送り状発行)"]
    end

    UI <--> Wallet
    Wallet <--> Blockchain
    API <--> Blockchain
    API <--> DB
    API <--> Oracle
    API <--> Warehouse
    Warehouse <--> DHL
```
