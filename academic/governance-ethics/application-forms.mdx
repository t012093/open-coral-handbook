# 倫理審査 申請書式・テンプレート集

倫理審査委員会へ申請する際に使用する公式テンプレート集です。各プロジェクトの文脈に合わせてダウンロード・カスタマイズして使用します。

---

## 申請様式一覧

| 様式番号 | 書式名称 | 用途・対象 | 形式 |
| :---: | :--- | :--- | :---: |
| **様式1** | **研究倫理審査申請書 兼 研究計画書** | 研究の背景、目的、方法、被験者数、リスク対策の記述 | Markdown / Word |
| **様式2** | **研究参加説明文書（市民・被験者用）** | 研究対象者への分かりやすい説明（平易な日本語） | Markdown / Word |
| **様式3** | **研究参加同意書 兼 同意撤回書** | 自由意思による参加同意および途中離脱の権利明記 | Markdown / PDF |
| **様式4** | **利益相反（COI）自己申告書** | 研究者個人の資金受領・兼業・役職の開示 | Markdown / Excel |
| **様式5** | **倫理審査判定結果通知書** | 委員会から申請者への審査結果通知（事務局用） | 公式フォーマット |

## 様式1：研究計画書 記載項目テンプレート

```markdown
# 研究倫理審査申請書 兼 研究計画書

申請日：令和　年　月　日
研究責任者：[氏名]（先端社会課題研究所 [役職]）
共同研究者：[氏名]（[所属]）

## 1. 研究課題名
（例：自治体オープンデータとAIエージェント協調による地域コモンズ意思決定支援に関する実証研究）

## 2. 研究の背景及び学術的独自性
・本研究が解決しようとする社会課題と、学術的新規性・実践的意義

## 3. 研究の目的及び対象
・達成しようとする具体的なリサーチクエスチョン
・研究対象者（募集方法、人数、選定・除外基準）

## 4. 研究の方法及び実施手順
・実施場所（富山拠点、オンライン等）
・収集するデータ（アンケート、対話ログ、行動ログ等）
・LLM等のAIツールの利用範囲

## 5. 対象者に生じる負担・リスク及びその最小化策
・身体的・心理的・時間的負担の評価
・個人情報漏洩リスクへの技術的対策（暗号化、匿名化、サーバー所在地）

## 6. 同意取得の手続き
・説明文書を用いた事前説明および同意書取得の方法
・未成年者が含まれる場合の代諾者同意手順

## 7. データの管理及び廃棄計画
・生データの保管場所、アクセス権限者、保存期間（原則10年）
・研究終了後の安全廃棄方法

## 8. 研究資金及び利益相反（COI）
・本研究に使用する研究費（科研費、民間助成金等）
・関連企業等との利害関係の有無
```

## 様式2：説明文書・同意書 骨子テンプレート

```markdown
# 【研究説明文書】研究へのご協力のお願い

研究課題名：○○○○に関する実証研究
研究責任者：楠 直哉（特定非営利活動法人 Open Coral Network 附置 先端社会課題研究所）

拝啓
このたび、当研究所では「AI協調による地域づくりの新しい仕組み」を検証するため、
地域の皆様を対象とした研究を実施することとなりました。
つきましては、本研究の趣旨をご理解いただき、ご協力をお願い申し上げます。

1. 研究の目的：地域の困りごとをAIを使ってスムーズに解決する方法を調べます。
2. ご協力いただく内容：約30分間のアンケートおよびワークショップへのご参加。
3. 参加の自由と撤回：参加は完全に自由です。断っても不利益は一切ありません。
   また、同意した後でも、いつでも理由なく参加を取り消すことができます。
4. プライバシーの保護：お名前や住所は数字の番号（ID）に置き換え、厳重に暗号化して保管します。
   研究成果は学会等で公表されますが、個人が特定されることは絶対にありません。
5. 費用と謝金：参加にかかる費用はありません。規定の謝金（図書カード等）を進呈いたします。
6. お問い合わせ窓口：先端社会課題研究所 倫理審査事務局（email: ethics@coral-network.com）
```
