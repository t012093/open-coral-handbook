## 1. 申請時の必須提出資料

研究責任者は、審査希望日の**2週間前**までに以下の資料一式を事務局（Nexloomまたは専用窓口）へ提出します。

| 提出資料 | 必須度 | 主な記載内容・確認ポイント |
| :--- | :---: | :--- |
| **研究計画書** | **必須** | 背景、学術的独自性、研究方法、対象者選定基準、リスク最小化策、個人情報管理計画 |
| **説明文書** | **必須** | 研究参加者に分かりやすい平易な日本語（中学生レベル）で書かれた説明資料 |
| **同意書（同意撤回書）** | **該当時** | 参加の任意性、いつでも無不利益で撤回できる旨の記載、署名欄 |
| **調査票・インタビューガイド** | **該当時** | 実際に市民や被験者へ配布・質問するアンケート設問や面接プロトコル |
| **利益相反（COI）申告書** | **必須** | 研究責任者および分担者の関連企業からの報酬、資金源、役職等の開示 |
| **個人情報・ログ管理計画書** | **必須** | データの暗号化、保管期間、匿名化手順、廃棄方法（サーバー所在地含む） |

## 2. 審査区分と判定基準

### 審査区分
- **本審査**: 新規案件、社会的影響が大きい案件、論点・リスクが多岐にわたる案件。
- **迅速審査**: 既承認研究の軽微な変更（調査期間の延長、文言修正等）、既存オープンデータの再分析等。

### 5大判定基準
1. **研究目的と手法の科学的妥当性**: 目的達成のためにその手法・データ収集が不可欠か。
2. **リスクと便益の均衡**: 対象者が被る負担・リスク（時間・精神的負担）が最小化され、社会的便益と調和しているか。
3. **説明文書の平易さと理解可能性**: 専門用語を避け、一般市民が十分理解できる表現になっているか。
4. **インフォームド・コンセント手続**: 強制や同調圧力がなく、真に自由意思に基づく同意が担保されているか。
5. **個人情報・生データの安全管理**: 漏洩防止、アクセス権限管理、研究終了後の安全廃棄が明確か。

## 3. 事務局オペレーションとLLM活用

事務局は、申請の受付、形式不備チェック、委員への資料配付、議事録作成、結果通知書の発行を担当します。

> [!TIP]
> **事務局におけるLLM（AI）の安全活用**:
> 事務局業務において、説明文書の「平易化チェック（中学生レベルの分かりやすさ検証）」や「論点サマリーの抽出」にLLMを活用することは推奨されます。ただし、倫理的・法的な最終判断は必ず委員会（人間）が行わなければなりません。
